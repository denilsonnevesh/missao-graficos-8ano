# Missão dos Gráficos — 8º Ano
Jogo multiplayer sobre leitura e interpretação de gráficos. Possui sala por código, modo professor/aluno, gráficos de barras/linhas/setores, perguntas progressivas, cronômetro e ranking.

## Render
Runtime Node | Build: `npm install` | Start: `npm start`

## Local
`npm install` e depois `npm start`; abrir `http://localhost:3000`.
